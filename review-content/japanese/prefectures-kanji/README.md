# Prefectures - 漢字

47 full prefecture names in kanji and hiragana; 94 precomposed bidirectional cards. Includes 都・道・府・県 in each applicable name and reading. Names cross-checked against J-LIS: https://www.j-lis.go.jp/spd/code-address/todouhuken/cms_16914188.html

Revision 2 adds one shared highlighted-prefecture map to the answer of both directions. Prompts remain text-only; 47 images are shared across 94 cards.
