# Korean Core Reviews

This directory is the authoritative WhackSmacker source for Korean core Review decks. The Korean curriculum repository owns chapters, translations, ledgers, vocabulary-form records, lexical topics, participant metadata, and paired Grammar Easy/Hard summaries.

Completed consecutive five-chapter inventory:

- Chapters 1–5: 47 canonical lexical senses / 94 bidirectional cards;
- Chapters 6–10: 45 canonical lexical senses / 90 bidirectional cards;
- Chapters 11–15: 40 canonical lexical senses / 80 bidirectional cards.

Every ordinary deck contains vocabulary/function-word cards only and requires one to three literal examples from primary Dialogue or Narrative content.
