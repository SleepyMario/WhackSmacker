# Chapter 11-15 Review Deck

Deck name: `Chapter 11-15`

This authoritative schema-v2 source deck contains 80 cards: both ordinary
review directions for all 40 canonical vocabulary items or lexical senses first
introduced in Korean Core Chapters 11–15. The count follows the inventory; it is
not a quota.

Scope:

- vocabulary and function-word Review only;
- bidirectional directions: Korean → English and English → Korean;
- full grammar-pattern cards excluded;
- canonical cast names and functional role labels excluded;
- grammar IDs and chapter titles excluded;
- every card has one to three literal examples from the primary Korean Dialogue
  or Narrative;
- stable card IDs, canonical lexical/sense IDs, first-introduction chapters,
  exact provenance, and NFC-normalized text are retained internally;
- distractor arrays are empty.
