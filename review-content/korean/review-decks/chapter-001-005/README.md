# Chapter I - V

34 lexical senses, 72 cards. One to three exact primary-reading examples per pair; no grammar identities or invented examples. Ordered by first introduction and source table order. Korean predicates retain their dictionary-form pair, with an English infinitive answer, and taught inflected forms receive a separate pair whose English answer names the speech level. Chapter I–V currently applies this to `반갑다` / `반갑습니다` and `감사하다` / `감사합니다`. No Japanese A/B/C retrieval format.
