# tmp2

Temporary formatting deck for the Simplified and Traditional Chinese conversion material.

- Source: Level I of the existing `通用规范汉字表` conversion deck.
- Selection: 20 distinct Simplified characters whose selected Traditional form differs.
- Cards: 40, comprising both conversion directions for every selected mapping.
- Sampling: fixed pseudo-random seed `0x57534d31`; the result is recorded in `selection.tsv` and must remain stable while formatting is revised.
- Content status: deliberately retains the current Level I wording. Generic example placeholders are expected to be replaced here before the full Level I deck is recreated.
