# Vietnamese Core Reviews

SPDX-License-Identifier: GPL-3.0-or-later

This directory is the authoritative WhackSmacker source for Vietnamese Core review decks. The review package is `com.sleepymario.language.vietnamese.reviews`, related to the reading curriculum package `com.sleepymario.language.vietnamese`.

Authoritative schema-v2 decks currently implemented through Chapter 30:

- `chapter-001-005`: 30 lexical senses represented by 60 bidirectional cards;
- `chapter-006-010`: 36 lexical senses represented by 72 bidirectional cards.
- `chapter-011-015`: 47 lexical senses represented by 94 bidirectional cards;
- `chapter-016-020`: 43 lexical senses represented by 86 bidirectional cards;
- `chapter-021-025`: 40 lexical senses represented by 80 bidirectional cards;
- `chapter-026-030`: 35 lexical senses represented by 70 bidirectional cards.

Each sense has Vietnamese-to-English and English-to-Vietnamese cards. Every card has an explicit stable identity, an accepted-answer set, no
distractors, canonical lexical references, literal learner-facing curriculum
provenance and example text, and a deterministic pedagogical fingerprint
generated into the package. Reading curricula may refer to these identities
but do not own or package these decks.

The six decks contain 231 canonical lexical senses and 462 directional cards in total.

## Authoritative Chapters 11–30 reviews

Review decks follow every completed five-chapter block through Chapter 30. Each deck contains all and only canonical lexical senses first introduced in its block, in both ordinary directions, with one to three literal Vietnamese primary-reading examples.

Chapters 11–30 introduce 165 review-eligible senses and therefore 330 directional cards. No fixed quota is used.
