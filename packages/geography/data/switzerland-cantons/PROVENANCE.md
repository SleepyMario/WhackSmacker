WhackSmacker preserves the source canton boundaries and geographic proportions. It adds learner-facing colours, numbered and named reference artwork, readable non-crossing callouts for small cantons, and one highlighted question/answer pair for each of Switzerland's 26 cantons.

The learner-facing English deck uses Geneva, Grisons, Lucerne, and Zurich where conventional English names exist. The retained source preserves the original source names and canton ISO codes.
