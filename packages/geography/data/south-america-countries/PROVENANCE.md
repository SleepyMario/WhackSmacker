# South America country map provenance

All boundaries are adapted from one consistent Natural Earth Vector
public-domain `ne_10m_admin_0_map_units` dataset, retrieved from the official
`nvkelso/natural-earth-vector` repository on 2026-10-05. The map uses a
South America-centred Albers equal-area projection rather than drawing raw
longitude and latitude as rectangular coordinates.

The learner set contains the 12 sovereign states conventionally grouped in
South America plus French Guiana, named `Guyana (France)` in this deck. It
remains constitutionally part of France;
its inclusion follows this deck family's geographic rule that all territories
are covered regardless of legal status. The rendering preserves country and
territory shapes and geographic relationships, using external numbered
callouts only where an in-map number would be difficult to read.
